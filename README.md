# Review da Reforma

Réplica exata e fiel do portal [Review da Reforma](https://reviewdareforma.com/).

## 📋 Conteúdo e Recursos
- **Identidade Visual e Cores:** Paleta oficial baseada em variáveis CSS (`--rf-primary: #b45309`, `--rf-accent: #fef3c7`, `--rf-dark: #292524`, etc.).
- **Tipografia e Diagramação:** Fontes serifadas no corpo (`Georgia`) e sem serifa nos elementos de interface (`Trebuchet MS`), com espaçamento e grid responsivo com barra lateral.
- **Conteúdo Integral:** Todos os textos, seções, tabelas de custos e prazos, caixas de destaque (dica e atenção), checklist e seções legais (Privacidade, Termos de Uso, Cookies).
- **Dados Estruturados (SEO):** Metatags completas, Open Graph e marcações JSON-LD (`WebSite`, `Article`, `Organization` e `HowTo`).
- **Interatividade:**
  - Banner de consentimento de cookies funcional com persistência no `localStorage`.
  - Botão de compartilhamento com cópia para área de transferência e feedback visual imediato.
  - Links diretos para compartilhamento via WhatsApp e E-mail.
  - Favicon em SVG integrado e arquivo avulso.

## 🚀 Como Visualizar
Você pode abrir o arquivo `index.html` diretamente no seu navegador de preferência ou rodar um servidor HTTP local:

```bash
# Usando Python 3
python3 -m http.server 8080

# Ou usando Node.js npx serve
npx serve .
```

Acesse: `http://localhost:8080`
